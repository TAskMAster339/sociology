# Гибридные и переходные общества

Материалы команды № 4 к защите «Паспорта общества». Сравниваем Японию эпохи Мэйдзи, Индию и Китай. В учебном мини-кейсе разбираем переезд из села в Бангалор.

## С чего начать

- **Вся работа в одном файле.** Откройте [сборник команды](output/pdf/09%20Все%20материалы%20команды.pdf). В нём шесть материалов по ролям, общий текст выступления и все семь слайдов. Из оглавления можно перейти к любому разделу.
- **Для подготовки по роли.** Найдите свой материал в таблице. В каждом документе есть тезисы, примеры, ответы на возможные вопросы и ссылки на источники.
- **Для репетиции.** Откройте сценарий и презентацию рядом. Выступает один человек. Целевое время доклада — 9 минут, регламент — 7–10 минут. Ещё 2–3 минуты отводятся на вопросы.
